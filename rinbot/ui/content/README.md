# RInBot 管理页面内容

当前管理入口由 src/data.ts 定义，业务页签由 src/admin-pages.ts 定义。显示编号按五个分组连续排列为 X-001 至 X-022；档案选择计数使用全局序号和固定总数，不随分组改变分母。收藏使用独立稳定 key，旧收藏不会因重编号错位。五列三维阵列必须各有至少一个管理入口；档案阵列、卡片和动效继续使用固定的 RhineLabUI 资源。

独立 360° 模型展示页已移除，入口、专用代码、样式和动效选项不再保留。专用装配模型移至 reference/rhinelabui/retired-assets/，只作素材追溯，不进入网页发布包。管理业务的三级页签继续保留。

开场影片独立按原始时间轴的 1.5 倍速播放，不叠加其他倍率。菜单/页面切换保持 3 倍速，包括卡片抽取与归位、切换镜头、正文揭示及业务页签过渡。其余动画恢复默认 1 倍速，包括待机/选择波纹、配色、悬停、普通窗口与文字数字滚动。真实时钟、网络轮询、机器人队列和定时任务不变；减少动效设置继续生效。

二级菜单直达工作区；三级只显示本工作区的业务页签。实现说明、访问记录、样例摘要与开发里程碑不作为管理页内容。功能页签必须连接实际 API，不能用通用状态卡冒充业务功能。管理令牌只留在当前页面内存，外部写入仍需确认；未知结果不重试。

原 RhineLabUI 文本样例保留在 rhine-reference.json 和 rhine-reference-archives/，仅用于源素材追溯，不参与网页构建，也不提供样例下载链接。

验证：npm run check:content（内容、层级、鉴权、分页和故障隔离），npm run build（类型检查、静态深链入口与打包）。预览可设置 RINBOT_API_TARGET 指向隔离 Rust API；默认是本机 3211，不连接 Node 3210。
